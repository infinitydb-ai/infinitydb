# InfinityDB Cloud Waitlist

InfinityDB Cloud is our upcoming managed cloud service for enterprise agent memory infrastructure.

**Local InfinityDB is open-source and free forever under the Apache 2.0 license.**

## Cloud Features (Coming Soon)

- **Multi-Tenant Managed Scaling**: Hosted Postgres with pgvector and Redis caching.
- **VPC & On-Premise Deployments**: Dedicated clusters for sensitive enterprise workloads.
- **Enterprise RBAC & Audit Trails**: Cryptographic proof compliance logs for SOC2, HIPAA, and GDPR.
- **Team Dashboard**: Centralized UI for viewing, editing, and auditing agent memories across your organization.
- **1-Click Migrations**: Drop-in compatible with SQLite, Mem0, and TencentDB databases.
