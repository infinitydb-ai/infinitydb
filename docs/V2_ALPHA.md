# InfinityDB Next v2 alpha workspace

The v2 alpha is integrated in the alpha-v2 directory, isolated from the stable 1.x Python and Node.js packages. It includes a SQLite reference store, optional development REST adapter, Python tests, a TypeScript HTTP client, Rust score-fusion primitives and a synthetic benchmark harness.

Start with the alpha workspace README. The workspace is not a production-ready replacement for the existing SDKs. Vector/ANN retrieval, authentication, encryption-at-rest, MCP transport, predictive prefetch, autonomous consolidation and multi-agent federation are not implemented. Benchmark artifacts are synthetic and do not support competitor-ranking claims.
