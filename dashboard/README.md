# InfinityDB Dashboard

Visual inspector and query explorer for InfinityDB L0-L6 layers.

## Quick Start

Run the dashboard server:

```bash
python dashboard/server.py
```

Open `http://localhost:8080` in your web browser.

## Features

- **⚡ Sub-5ms Recall Explorer**: Live query test interface with real-time latency readout.
- **Atomic Facts Table (L1)**: Deterministic fact breakdown with category and importance tagging.
- **Causal Graph (L2)**: Visual representation of cause-and-effect reasoning.
- **Dynamic Persona (L3)**: Conflict auto-resolution view tracking user preferences over time.
- **Enterprise Policies (L4)**: System-wide guardrails and compliance rules.
- **Cryptographic Proof Chain (L6)**: Verifiable SHA-256 provenance linking atoms back to raw logs.
